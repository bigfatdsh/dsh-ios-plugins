# 课堂演讲 PPT 标准（现行版）

> 本文件是**版式标准的唯一来源**。记忆库里的
> `preferences/课堂演讲课件-ppt-讲稿-固定标准.md` 与本文同步；两处冲突时以本文为准，
> 改完本文要回头改记忆库，反之亦然。
>
> 已落地的样本：马原第五章第二节（23 页 / 20 分钟）、中华民族伟大复兴（18 页 / 11 分钟）。
> 两次都是「深色 + 浅色两版 pptx + 一份 docx 讲稿」。

---

## 1. 交付物

- 同名页的深、浅两版 pptx。深色＝墨黑底、米白字、朱红强调；浅色＝米白纸感、墨字。
  教室灯亮、投影发灰时用浅色版；两版页序完全一致，讲稿页码通用。
- 一份 docx 讲稿：逐页对应，标时长、动作提示、逐字稿。
- 一页「材料出处」，只写出处，不停留。

## 2. 结构

封面 → 钩子页（一个具体的人/地/数字）→ 路线图（三部分）→
反转色章节页（01 / 02 / 03）→ 内容页 → 数据页 → 案例页（对比）→ 细节页 → 收尾 → 出处。

节奏靠**章节页的反转色**，不靠装饰。一页一个意思，一页至少一个能指认的东西
（时间、地点、数字、动作、原话）。

## 3. 字号

| 位置 | 字号 |
|---|---|
| 封面主标题 | 72–82pt |
| 页面标题 | 40–46pt |
| 章节页标题 | 60–64pt |
| 正文 | 26–32pt |
| 卡片/引文 | 20–30pt |
| 页脚 | 13–16pt |
| 页码 | 13pt |
| 大数字 | 50–168pt |

宁可减字，也不缩字号。用户说「字体大些」时，正文取 28–30pt、标题 44pt 起。

## 4. 排版铁律

1. **显式坐标 + 手工断行**。文字按实测字宽断行（`\n` 分段），`word_wrap=False`，
   不自动缩放。教室机器没装同名中文字体也不会重排。
2. **块间最小间距 0.25 英寸**。正文块、引文卡、图注、页脚之间至少留这么多；
   只留 0.1–0.2 英寸时，换行一多就会压上去。
3. **按「估算行数 + 1 行」预留高度**。PIL 量出来的行数与 PowerPoint 的实际换行
   永远有误差（字体、字距、标点挤压），少留的那一行就是事故现场。
4. **下一块的 y 由上一块的实际底边推算**，不要写死。写死 y 的页面，只要有一段
   长了半行，就会连锁重叠。
5. **数字与单位必须紧贴**：放进同一个文本框、同一个段落，用两个 run
   （数字大字号 + 单位小字号）自然贴合。禁止用空格、全角空格、右对齐宽框把单位推开。
6. **数字框宽度 = 实测字宽 + 0.14 英寸**，不要固定 3.0 英寸这类「够用就行」的框——
   框虚宽会让旁边的单位、注释跟着漂。
7. **末行不超过 4 个字**（孤字）。出现孤字就改文案或改字号，不做拉伸。
8. **对比度**：正文与底色亮度差 ≥ 3:1。深色主题的章节页必须显式给
   `inv_bg` / `inv_text`，不能拿 `ink` 当底色——浅色主题下曾出现黑字压黑底。
9. 封面整幅底图压暗 50% 左右，底图不参与重叠检查。

## 5. 自检（交付前必须全过）

每页建完跑四项，全部为 0 才允许导出：

1. 越界：任何内容框不得出安全区（左右 0.95 英寸、上 0.36、下 0.22）。
2. 重叠：任意两个内容框交叠面积 > 0.09×0.09 英寸即报错。装饰元素用 `deco` 标记跳过。
3. 文字超高：按实际行数 × 行高与框高比对。
4. 单行超宽：断行后每行宽度必须小于框宽。

导出后**逐页看预览图**。坐标检查只能证明「框没重叠」，证明不了「字压字」——
本次 P2 就是框没重叠、字撑出来了。预览图是最后一道关。

## 6. 动效

只用 PowerPoint 原生动画，不引第三方：

- 每页 `p:transition` 用 `fade`，`spd="med"`。
- 条目动画 `presetID=10`（淡入），`presetClass="entr"`，`presetSubtype="0"`。
- 第一组 `nodeType="clickEffect"`，后续组 `afterEffect`，组内 `withEffect`。
  点一下、整页自动流完，再点翻页。
- 组间留 90–150ms 的 `delay`，不要 0 连播，也不要 300ms 以上（会像卡顿）。
- `cTn id` 每页唯一、`spTgt` 必须命中真实形状 id。
- `p:transition` 必须排在 `p:timing` 之前。

## 7. 讲稿

- 每页一段：`P+页码 · 页名 ｜ 约 N 秒`，下面一行 `〔动作提示〕`，再下面逐字稿。
- 正文按 250 字/分钟估算，总时长含停顿；末尾给「超时了砍哪句」的兜底。
- 方括号里的话不念，是给讲者看的。
- 附 5 个可能被问到的问题和答案。
- 提及的数据必须能在最后一页的出处里找到。

## 8. 踩过的坑（按时间倒序）

### 2026-11 中华民族伟大复兴（18 页）

**P2 文字堆叠。** 正文 27pt 手工断成 3 行，放在 y=1.52；红色注解放在 y=4.34。
估算是 3 行，PowerPoint 实际排了 4 行（数字与标点挤压），正文底边从 3.9 撑到 4.35，
正好压在注解上。同样的错误还有卡片盖文字。
→ 修法：按「估算行数 + 1 行」预留；块间至少 0.25 英寸；下一块的 y 由上一块实际底边推算。

**数字与单位离得太远。** 单位位置写成 `数字左边界 + text_w(数字) + 0.14`，
而 `text_w` 对半角数字的系数偏大（1.16），PowerPoint 里实际字宽更窄，
结果「140.19 万亿元」中间隔着将近 1 英寸。
→ 修法：数字与单位放同一个段落、两个 run，让字形自己贴着；或用「数字框右对齐 + 单位框左对齐，
间距固定 0.08 英寸」。绝不用手动空格或宽框对齐。

**深色版章节页黑字压黑底。** `desc` 与大字数字误用了 `th["dark"]`（浅色主题下是深绿黑），
在深色背景上完全看不见。
→ 修法：主题里显式定义 `ghost`（水印大字）与 `muted`（次级文字），不要混用 `dark`。

### 更早的马原课件

- 数据条必须统一比例尺并带基线刻度。曾把 scale 写成 0.36，两根条都顶到边、看着一样长。
- 自动断行会切进词中间（如「平方/米」「决/定」），必须手工断。
- 引文字号不得为排版让步。加引文条后正文被压到 26pt 会被判「原文字体太小」，
  宁可把引文改成页面底部的脚注卡。

## 9. 内容要求

- 教材内容要落到具体章节；引文措辞逐句核对教材或配套教辅，标点以书为准。
- 查不到页码时只标到节，不编页码。
- 数据必须有出处：统计公报、新华社、部委通报、地方政府公开报道。
- 案例优先选一个能讲透的具体对象（一个村、一条街、一户人家），不要罗列五个。
